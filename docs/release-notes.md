**First public beta.** Expect rough edges, and please report anything odd in
[Issues](https://github.com/Buutyful/GenshinTrainingWheels/issues).

## Install

Download `Genshin.Training.Wheels_…_x64-setup.exe` below and run it. Windows 10/11, 64-bit.

The app is free and **not code-signed**, so Windows does not recognise the publisher:

- **SmartScreen** says "Windows protected your PC": choose *More info → Run anyway*.
- **Smart App Control** (Windows 11, only if switched on) blocks unsigned apps with no way
  around it. Check it under Windows Security → App & browser control → Smart App Control.

It only reads your keyboard and mouse. It does not read the game's memory or screen, inject
anything, or send any input.

## What's in it

- **Loadouts**: four characters from a searchable roster with portraits, and the rotation
  typed in KQM / Hexenzirkel notation or built with buttons. Imports gcsim and Genshin
  Optimizer configs.
- **Practice mode**: follows where you are in the rotation from your inputs and cues the next
  move through your headphones, early enough to react to.
- **Rhythm mode**: turns one of your clean laps into a backing track and judges each step
  against the beat, with latency calibration.
- **Run recap**: a verdict, the three things to work on next, a heat-map of where in the
  rotation mistakes happen, timing, laps and per-character stats. Trends over runs per loadout.

## Known limits

- Windows only.
- No auto-update yet: download new versions from this page.
- Settings and loadouts are kept when you install a newer version over this one.
