**Third beta.** Expect rough edges, and please report anything odd in
[Issues](https://github.com/Buutyful/GenshinTrainingWheels/issues).

Already on an earlier beta? Install this over it: your loadouts, runs and settings are kept.

## What's new

- **Rotation timeline.** The run recap's breakdown now opens with a lane per character: each
  action sits where you pressed it, as wide as it took, and is tinted by how often it went
  wrong. Hover an action for its mistakes and timing. When the rotation has an opener, a
  dashed line marks where the loop starts.

## New in beta 2

- **Ladders with friends.** Every loadout has a ladder on its Metrics page, ranked by best
  clean lap. *Share my result* gives you a code to send to friends; paste theirs with
  *Add a friend's result*, or in *Import* on the home screen. A code carries the loadout too,
  so a friend who doesn't have it gets it from your code. Results only count on exactly the
  same rotation and team.
- **Rotation breakdown.** The run recap now lays the rotation out turn by turn: when each
  character's turn starts and ends, the actions, time on field against your plan, what went
  wrong there this run, and a note you can write for each turn (buffs, cooldowns, what it
  sets up).
- **Clearer team stats.** Each character is one row: share of field time, inputs and how many
  of their steps went right.
- The tips under *Focus next* now also point out the turn that loses the most time.

Turn timings are recorded from this version on, so runs from beta 1 show planned times only.

## Install

Download `Genshin.Training.Wheels_…_x64-setup.exe` below and run it. Windows 10/11, 64-bit.

The app is free and **not code-signed**, so Windows does not recognise the publisher:

- **SmartScreen** says "Windows protected your PC": choose *More info → Run anyway*.
- **Smart App Control** (Windows 11, only if switched on) blocks unsigned apps with no way
  around it. Check it under Windows Security → App & browser control → Smart App Control.

It only reads your keyboard and mouse. It does not read the game's memory or screen, inject
anything, or send any input.

## What's in it

- **Loadouts**: four characters from a searchable roster with portraits, and the rotation
  typed in KQM / Hexenzirkel notation or built with buttons. Imports gcsim and Genshin
  Optimizer configs.
- **Practice mode**: follows where you are in the rotation from your inputs and cues the next
  move through your headphones, early enough to react to.
- **Rhythm mode**: turns one of your clean laps into a backing track and judges each step
  against the beat, with latency calibration.
- **Run recap**: a verdict, the three things to work on next, a per-character timeline and turn-by-turn breakdown,
  timing, laps and per-character stats. Trends over runs and a ladder per loadout.

## Known limits

- Windows only.
- No auto-update yet: download new versions from this page.
- Ladder codes are not signed: they are for comparing with friends, not a cheat-proof
  leaderboard.
